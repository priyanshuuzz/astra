## 2025-05-10 - Hospital Capability Lookup Optimization
**Learning:** In ASTRA's recommendation engine, `hasCapability` was called repeatedly for each required capability key during hospital ranking. Per call, `[...hospital.specialties, ...hospital.facilities].map(norm)` created array allocations and executed regex string lowercasing/replacements multiple times per hospital score. Pre-computing a normalized haystack array once per hospital evaluation in `HospitalRecommendationEngine.score` and using indexed `for` loops reduced capability checking runtime by ~55% (2.2x speedup).
**Action:** When performing multi-attribute capability or filter matching over objects with nested text arrays in hot scoring loops, pre-compute normalized search targets once per object before iterating over criteria.
