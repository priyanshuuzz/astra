## 2026-03-31 - WeakMap Caching & Loop Optimization for Scoring Engines
**Learning:** In hot recommendation scoring routines (e.g. `HospitalRecommendationEngine`), repeatedly normalizing text strings (`[...specialties, ...facilities].map(norm)`) and allocating temporary arrays during capability checks created severe GC overhead and high CPU time (~3000ms per 30k ranking operations). Using a `WeakMap<Hospital, string[]>` to memoize the normalized search haystack per hospital object along with imperative nested loops for alias searching reduced ranking time by ~65% (down to ~1060ms per 30k operations).
**Action:** When evaluating records repeatedly against dynamic criteria or user filters in React/React Native apps, cache normalized text representations in a WeakMap keyed on the domain object rather than re-normalizing per evaluation.
