## 2026-03-26 - Hospital Recommendation Engine Optimization & Safe WeakMap Caching
**Learning:** Caching computed/normalized properties directly on input objects (`object._cache = ...`) poses runtime crash risks when objects are frozen or proxied in state managers (React State/Zustand/Redux). Using a module-level `WeakMap<Object, ComputedValue>` delivers the exact same O(1) cache lookup performance safely without mutating inputs. Furthermore, pre-normalizing lookup tables at module initialization and hoisting constant conversion factors in haversine distance calculations yields significant execution speedup (~62% reduction in ranking benchmark time).
**Action:** Always prefer `WeakMap` for caching derived properties on domain model objects, and pre-normalize fixed lookup dictionaries at module scope.
