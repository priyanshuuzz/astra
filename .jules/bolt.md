## 2025-05-20 - Hospital Ranking Capability Allocation & Search Memoization
**Learning:** Calling capability matching without a pre-computed haystack caused redundant string normalization (`toLowerCase()`, regex replace, `trim()`) and array allocations across all required capability checks for every hospital. Pre-building the normalized haystack once per hospital reduced execution time of `HospitalRecommendationEngine.rank` by ~55% (from ~1.48s to ~0.66s across 500 hospital records x 100 iterations). Furthermore, bundling full hospital ranking inside a single `useMemo` with user search `query` triggered complete re-ranking on every single keystroke.
**Action:** Always pre-compute/cache normalized string sets before iterating over sub-capability checks, and decouple base list computations from user-controlled search/filter query state in React `useMemo` hooks.
